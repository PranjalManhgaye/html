# Single Page Resume Website (HTML Only)

## Overview
This project is a simple single-page resume website created using **only HTML**.  
No CSS or JavaScript has been used, as the main goal of this assignment is to
understand proper HTML structure, semantic tags, and clean layout.

The website contains all the basic sections of a resume such as personal
information, skills, experience, projects, education, and contact details.

---

## Features
- Single HTML file
- No external libraries
- No CSS or JavaScript
- Clean and readable structure
- Uses semantic HTML tags like:
  - headings
  - paragraphs
  - lists
  - tables
  - sections

---

## Sections Included
- Header (Name and short description)
- About section
- Skills list
- Experience table
- Projects section
- Education table
- Contact details

---

## How to Run the Project
1. Clone the repository or download the ZIP file
2. Open the `index.html` file
3. View it in any modern web browser (Chrome, Edge, Firefox, etc.)

No additional setup is required.
